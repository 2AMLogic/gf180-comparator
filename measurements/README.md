# measurements/

Measured/derived results with their evidence chains.

## What lives here

This directory holds the **derived, narrative layer** of this block's
measurement story — documents that interpret and score the committed
evidence. The measured evidence itself lives in
[`sim/<experiment>/records/`](../sim/README.md) (append-only: per-corner
result tables, raw ngspice logs, and a machine-readable copy per record);
nothing in this directory ever supersedes a `sim/` record.

## Contents

- [`characterization-report.md`](characterization-report.md) — the
  **narrative characterization report**: the four experiments (offset-mc,
  preamp-noise, regeneration, kickback) tied together and scored against the
  target-specification table as ratified by
  [DR-0002](../spec/decision-records/DR-0002-target-spec-ratification.md)
  (T1 checklist item 8), with the two known gaps (decision-time stretch miss
  at `ss_125c_2.97v`; kickback target/stretch miss) stated explicitly rather
  than absorbed. Each experiment's numbers cite the specific evidence record
  they come from.
- [`characterization-report.item8.json`](characterization-report.item8.json)
  — the **generic evidence envelope** (`"kind": "generic"`, the one T1 item
  that accepts one) wrapping that report for the T1 signoff citation:
  `signoff/make_item8_envelope.py` writes it deterministically, pinning the
  report's sha256 in `provenance.input.content_hash`. The envelope's `pass`
  asserts the report's existence, currency and evidence chain — the two
  scored misses stand as recorded in the report, named in the envelope's
  `summary`. See [`signoff/README.md`](../signoff/README.md)'s item-8
  section.

## Reproducibility

Every result the report scores is regenerated by the one-command driver
[`sim/characterize.sh`](../sim/characterize.sh) (`smoke` /
`characterize` / `selftest` — see [`sim/README.md`](../sim/README.md) for the
cold-start path). The narrative report itself is hand-written and cites that
output; a re-run mints new dated evidence records, it does not rewrite
`sim/`'s committed history or this report.
