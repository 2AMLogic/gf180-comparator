- **Monte-Carlo seed / draws**: ngspice `setseed 20260909` at the top of the control block, then 200 draws per PVT point via `reset` inside a `dowhile` loop (each reset re-evaluates the agauss expressions in the PDK's fets_mm subcircuits). The SAME seed is used at every PVT point -- common random numbers -- so movement of the reported sigma across the grid is a real PVT effect and not sampling noise; N for statistical-error purposes is 200, not 200 x 45. `setseed <n>` is the only ngspice seeding control that works for this: `set rndseed` is silently ignored and `.options seed` freezes the draw.
- **Monte-Carlo scope**: mismatch-only (sw_stat_mismatch = 1, sw_stat_global left at the PDK default 0). Global process variation is swept deterministically by the corner axis instead, so the two are never confounded in one number.
- **Sigma derivation**: 1-sigma of the input-referred offset is reported directly, alongside the 3-sigma value README.md's offset row is stated at. Statistical precision on each sigma is 1/sqrt(2N) = 5.0 % at N = 200. Offset per draw is -dv(0 mV)/A_v where A_v is measured on the SAME draw from the 0 mV and +2 mV points of one `dc` sweep; av_sigma_pct is the check that the draw really was preserved between them.
- **Note**: TWO DC POINTS PER DRAW, ONE INSTANCE. Gain is measured inside a single `dc` sweep of the shared differential source, not from a second instance. Two instances would have independent mismatch draws, so their difference would contain an offset difference rather than just the gain.
